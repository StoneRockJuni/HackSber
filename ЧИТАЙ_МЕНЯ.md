# СтройКонтур — AI-мониторинг объектов ИЖС (hackSber)

Прототип: по аэрофотоснимкам с дрона определяет стадию строительства частного
дома (0 / 50 / 100 %), проверяет подлинность снимка и выбирает одну из 8
кредитных стратегий.

---

## Как запустить (3 шага)

**Шаг 1. Поставить Python 3.13** (если ещё нет): https://www.python.org/downloads/
При установке галочка **«Add python.exe to PATH»**.

**Шаг 2. Один раз создать окружение.** Открыть терминал в этой папке
(в проводнике: `Shift` + правая кнопка мыши → «Открыть окно PowerShell здесь»)
и выполнить:

```powershell
cd PythonProject
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
cd ..
```

Это скачает библиотеки (~300 МБ), займёт пару минут.

**Шаг 3. Запустить:**

двойной клик по **`run.bat`** в этой папке.

Через ~5 секунд откроется браузер. Если не открылся — зайдите вручную на
адрес, который напечатается в консоли (обычно `http://localhost:8501`).

Остановить: `Ctrl+C` в окне консоли.

> Если порт занят, `run.bat` сам возьмёт следующий (8502, 8503…) и откроет
> браузер на нём. Слушает только `127.0.0.1` — из сети приложение недоступно.

## Что посмотреть за 5 минут

1. **Главная страница** → в сайдбаре выберите участок → загрузите
   `PythonProject\demo_data\demo_object_2_ok.jpg`.
   Ожидаемо: стадия **100 %**, стратегия **7** (дом готов, но не в залоге),
   уровень доказанности **сильная**.
2. Загрузите `demo_object_1_ok.jpg` → стадия **50 %**.
3. Загрузите `demo_fraud_no_exif.jpg` → стратегия **6** (СУБ, риск фрода).
4. Слева в сайдбаре откройте страницу **«🔬 Песочница»** и загрузите **любое**
   своё фото (или вставьте ссылку) — увидите, откуда берутся координаты, что
   видит нейросеть и почему решение не принимается.
5. Нажмите «Зафиксировать решение» → появится запись в журнале аудита, потом
   «Проверить целостность журнала».

## Что внутри архива

| Что | Зачем |
|---|---|
| `run.bat` | запуск одним кликом |
| `PythonProject\` | всё приложение: интерфейс, нейросеть, безопасность, тесты |
| `PythonProject\docs\` | 6 документов: простыми словами, разбор интерфейса, безопасность, валидация ИИ, что изменилось |
| `PythonProject\models\` | файлы нейросети (ONNX) и её метрики |
| `PythonProject\demo_data\` | 3 демо-снимка без реальных персональных данных |
| `PythonProject\SberStroi_dataset\` | датасет (50 размеченных снимков) и скрипты обучения |
| `SberStroi.ipynb` | ноутбук обучения (Google Colab, 50 эпох, 6 классов) |

Чего **нет** и почему:

* `.venv` — окружение Python весит сотни мегабайт и привязано к компьютеру;
  создаётся за 2 минуты по шагу 2.
* `домики\` — исходный архив фото с дрона, **521 МБ**; к тому же это реальные
  снимки объектов, их не стоит пересылать.
* `runs\` — промежуточные артефакты обучения (60 МБ), для запуска не нужны.
* концепция и положение хакатона — к коду не относятся.

## Что честно не сделано

* Модель обучена на **50 снимках двух объектов** — промышленную точность не
  обещаем; честная оценка на отложенной выборке: точность стадии 0.40.
* Нет входа по паролю и разделения ролей.
* Журнал аудита защищён от правки в середине цепочки, но не от удаления файла
  целиком (для этого нужно WORM-хранилище).
* Интеграции с АС «Калита» нет — выгрузка акта демонстрационная.
* Материал стен не определяется (всегда «неизвестно»).
* Цифры в верхней панели (17 800 кредитов, «в 14 раз быстрее») — из кейса,
  а не из базы банка.
